# 记忆卡

<ItemImage id="memory_card" scale="4" />

内存卡用于复制和粘贴设置 AE2[设备](../ae2-mechanics/devices.md)链接
[P2P 隧道](p2p_tunnels.md)也可以粘贴[升级卡卡](upgrade_cards.md)进入设备。

- 点击 Shift- right 即单击 Shik- 右键以复制设置或生成新的 P2P 连接频率。
- 单击右键粘贴设置、升级卡片或连接频率。
