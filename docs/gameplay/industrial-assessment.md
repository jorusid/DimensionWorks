# 工业能力考核体系设计

## 1. 设计定位

本设计以教育部《普通高中化学课程标准（2017年版2020年修订）》为能力培养参考，借鉴其核心素养、真实问题情境、探究活动与学业质量评价思路，但不把化学试题直接搬进 Minecraft。

**核心原则：玩家应通过独立完成一项真实的工业任务，证明自己学会了相关机制。**

知道机器配方、用途或原理只是基础认知。玩家能够选择设备、组织工序、规划物流、处理动力与产能约束，并在条件变化后诊断和调整系统，才体现出实际掌握。任务应说明目标、约束和验收条件，但不直接给出完整机器清单、摆放方案或传输线路。

本文件是工业玩法与关键进度设计的长期依据。具体任务与配方必须结合仓库现有模组、实际机制和科技流程制定，不得脱离实现条件凭空设计。

## 2. 课程核心素养向工业能力的转译

以下对应关系是 DimensionWorks 的设计转译，并非课程标准原文。

| 化学核心素养 | 整合包中的工业能力 | 可观察的验证表现 |
| --- | --- | --- |
| 宏观辨识与微观探析 | 理解物料性质、机器机制与加工结果之间的关系 | 能正确组织工艺链，处理不同材料和中间产物 |
| 变化观念与平衡思想 | 理解转化条件、产能、能源消耗和物料平衡 | 产线能够持续运行，输入输出关系合理 |
| 证据推理与模型认知 | 根据现象判断故障原因，建立对工业系统的理解 | 遇到堵塞、缺料或产能不足时能够定位原因 |
| 科学探究与创新意识 | 独立设计、搭建和改进生产系统 | 能构建可运行方案，并适应新的生产要求 |
| 科学态度与社会责任 | 重视资源利用、废料处理、效率与长期运行 | 系统能处理副产物、控制浪费并稳定运转 |

## 3. 工业能力的五级模型

该分级是本整合包的设计模型，不是对高中化学学业质量等级的照搬。

### Ⅰ：理解单一工艺

玩家通过实际操作理解一种机制的输入、输出、加工条件及动力要求。

**验收方向：** 完成真实有效的加工过程，而非仅合成机器。

### Ⅱ：组织多道工序

玩家将多个加工步骤衔接起来，解决中间物料传递、工序顺序和输入供给问题。

**验收方向：** 完整产线能够持续产出目标材料，而非逐个手动加工。

### Ⅲ：掌握工业系统约束

玩家协调动力、吞吐量、存储、物流、副产物和能源供应，理解局部机器正常不代表整条产线正常。

**验收方向：** 系统在持续运行条件下满足产量要求，并妥善处理瓶颈。

### Ⅳ：独立解决综合工程问题

玩家组合已掌握的机制，建立跨机器、跨模组，必要时跨维度的生产系统。

**验收方向：** 系统能够完成新的综合目标，不能只靠复刻某张固定配方或模板。

### Ⅴ：迁移、诊断与优化

玩家将旧知识应用于陌生工艺，识别效率瓶颈，设计可靠的替代方案，并处理系统间的耦合关系。

**验收方向：** 面对新约束仍能构建可行系统，而不是只能运行已有模板。

## 4. 任务设计规则

1. **目标明确，解法开放。** 说明产物、运行要求和必要约束，不规定唯一机器摆放方案；满足约束的合理方案均应被接受。
2. **观察真实系统行为。** 尽可能依据实际产出、连续运行、输入输出关系、物流完整性和副产物处理进行验收，而不是让玩家回答选择题。
3. **故障是学习的一部分。** 玩家应能依据可观察现象定位问题。必要提示应逐步揭示方向，而非直接提供完整解法。
4. **后期要求知识迁移。** 若玩家只需替换材料、复制旧产线即可通过后期任务，就没有真正考核更高层次的理解。
5. **能力目标先于配方设计。** 若无法明确说明一项关键进度考核什么能力，就不应先开始编写其配方。

## 5. 低成本绕过审查

设计关键物品、修复碎片和阶段进度时，必须从整合包整体检查绕过路径，而不只检查目标配方本身。

- **手工合成可以保留。** 但若它绕过预期工业流程，应付出明显更高且可衡量的材料、时间或操作成本；它可以是备用路线，不应成为最优解。
- **单台机器不能廉价刷穿科技。** 关键产出应受到真实工艺条件、前后工序、输入供给、动力、吞吐量、物流或副产物循环等因素约束。
- **难度来自理解与工程，而非单纯堆料。** 增加材料数量或等待时间本身不代表能力考核。
- **自动化应有实质优势。** 在持续产出、资源效率、操作负担和扩展能力方面，工业路线应显著优于低成本手工替代。
- **检查跨模组替代路径。** 覆盖其他模组的机器、替代配方、重复加工、循环配方、副产物回收及跨系统转换，避免捷径破坏阶段目标。
- **避免矫枉过正。** 不应为封堵绕过路线而删除所有手工配方，也不应让自动化仅靠漫长等待完成。目标是让工业路线因效率、持续性和扩展能力而有意义。

## 6. 七个齿轮之心修复碎片

七个修复碎片应共同构成贯穿整合包流程的能力进阶路径。每个碎片应主要验证一种在前一阶段尚未被充分考核、也不能被旧能力轻易替代的工业能力；后期可以综合调用前期能力。

在确定各碎片材料和配方前，先为其建立设计档案，至少包含：

- **学习目标：** 玩家必须理解什么原理或关系。
- **工程目标：** 玩家必须实际建成或完成什么。
- **必要约束：** 为什么单机、手工合成或简单堆料不能廉价替代。
- **验收标准：** 通过什么可观察的运行结果确认完成。
- **迁移要求：** 如何证明玩家掌握机制，而不只是照抄固定流程。
- **绕过审查：** 是否存在其他模组的替代配方、资源循环或刷取机制破坏考核。

碎片的能力分配尚待单独设计与审核；不得仅按科技等级机械分配，也不得在能力目标未确定前预设具体配方。

## 7. 终局目标

终局应要求玩家综合运用整套工业体系，独立解决跨系统问题。终极物品应体现玩家掌握整套工业体系后的工程成果，而不只是收集齐七份材料后得到的奖励。

评估设计时始终坚持：**玩家完成任务，不自动等于玩家掌握能力；应尽可能通过工业系统的实际运行表现验证。**
